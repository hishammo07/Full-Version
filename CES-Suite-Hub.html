How the tools talk to each other

One clipboard hand-off, matched by code — never duplicated

Pump Selector and the Accessories Selector don't hold prices — they hold specs and catalogue codes. The BOQ Studio is where those become priced line items.

01

Pick a product

In Pump Selector or Accessories Selector, open any result card or its detail view.

02

Send to BOQ

One tap copies it to the clipboard in a shared format made just for these three tools.

03

Import from Tool

Back in the BOQ Studio's dock, one tap drops it into the Mechanical BOQ.

No ambiguity, by design: matching happens only by product code, never by name. Sending the same item twice updates its existing BOQ line — it never creates a duplicate. A new code always lands under a clearly labelled "Imported from Tools" section, ready to review.
